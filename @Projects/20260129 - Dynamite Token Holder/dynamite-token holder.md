# Ideia

Fazer um porta exploration token para o Shadows of Brimstone em forma de "dynamite".

É um cilindro com tampa de rosca todo vermelho (cilindro e tampa). Na tampa tem um furo onde passa o "pavio" preto (pode ser feito com fio de aço ou impresso.

Na base do cilindro tem um slot para tirar a peça (da altura da peça) para tirar o token. Do lado oposto tem um lugar para empurrar com o dedo.

Pose-se imprimir uma base mais larga para encaixar no cilindro e facilitar deixá-lo em pé. Ou só um cilindro para girar e liberar
